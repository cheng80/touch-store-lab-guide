# Google Play 게임 출시 실무 안내서

[이미지 포함 출시 가이드 열기](https://cheng80.github.io/touch-store-lab-guide/)

콘솔 등록부터 유료 아이템·환불 검증·프로덕션 출시까지의 절차를 담은 한국어 HTML 안내서입니다. 본문과 이미지가 `index.html` 한 파일에 포함됩니다.

비공개 프로젝트의 원본 HTML을 GitHub Actions가 이 저장소로 동기화합니다. 이 저장소에는 가이드와 Pages 발행 설정만 보관합니다. 게임 소스·빌드·자격증명은 포함하지 않습니다. 수정은 원본 프로젝트에서 진행합니다.

`main`의 `index.html` 변경 시 [Pages 발행 워크플로](https://github.com/cheng80/touch-store-lab-guide/actions/workflows/public-pages.yml)가 실행됩니다. 필요하면 Actions의 **Run workflow**로 재배포합니다. 배포 상태는 Actions의 성공 결과와 실제 사이트를 함께 확인합니다.
